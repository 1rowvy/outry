## CLI

<Tabs>
<TabItem label="Linux">

```sh
curl -fsSL https://raw.githubusercontent.com/1rowvy/outry/master/install.sh | sh
```

Скрипт скачивает статический бинарь из последнего релиза (x86_64 или aarch64 — работает на любом
дистрибутиве, включая Alpine), проверяет контрольную сумму SHA-256 и кладёт его в `~/.local/bin/outry`.
Заодно он включает автодополнение для fish и bash; для zsh добавьте `source <(outry completions zsh)` в
`~/.zshrc`. Подсказки генерирует установленный бинарь, поэтому после `outry update` они сразу новые.

Настройки передаются переменными окружения:

```sh
# конкретная версия
curl -fsSL https://raw.githubusercontent.com/1rowvy/outry/master/install.sh | OUTRY_VERSION=v0.2.0 sh

# для всех пользователей (обновлять потом через `sudo outry update`)
curl -fsSL https://raw.githubusercontent.com/1rowvy/outry/master/install.sh | sudo OUTRY_INSTALL_DIR=/usr/local/bin sh
```

</TabItem>
<TabItem label="macOS / Windows">

Скачайте `outry-cli-<версия>-<платформа>` из
[последнего релиза](https://github.com/1rowvy/outry/releases/latest), распакуйте и положите `outry`
(`outry.exe`) в любую папку из `PATH`. Рядом с каждым архивом лежит файл `.sha256`.

Скрипт установки для этих платформ в планах.

</TabItem>

### Обновление

```sh
outry update           # скачать и поставить последний релиз (с проверкой SHA-256)
outry update --check   # только проверить, есть ли новая версия
```

Как и npm, Outry раз в сутки в фоне проверяет новую версию и после команды коротко напоминает, если она
вышла. Команды при этом сеть не ждут. Напоминание не показывается в пайпах, в CI и при
`OUTRY_NO_UPDATE_NOTIFIER=1`.

<Aside>
Если `outry` поставлен пакетным менеджером (`/usr/bin`, Homebrew, Nix), `outry update` его не трогает —
обновляйте тем же пакетным менеджером.
</Aside>

### Удаление

```sh
rm ~/.local/bin/outry                                    # бинарь
rm ~/.config/fish/completions/outry.fish                 # автодополнение
rm ~/.local/share/bash-completion/completions/outry
rm -rf ~/.local/share/outry ~/.cache/outry               # сохранённые значения, история, кэш ответов
```

На macOS данные лежат в `~/Library/Application Support/outry` и `~/Library/Caches/outry`.
Секреты остаются в системном хранилище паролей: удалите их через `outry secret rm <ИМЯ> --env <ОКРУЖЕНИЕ>`
до удаления бинаря или в приложении хранилища (записи с именем `outry`). Ваши `.outry`-файлы и `env.toml`
лежат в репозиториях и не затрагиваются.

Чтобы переустановить начисто, выполните команды выше и снова запустите скрипт установки.

## Приложение

Установщики для macOS (`.dmg`), Windows (`.exe`, `.msi`) и Linux (AppImage, `.deb`, `.rpm`) — на
[странице релизов](https://github.com/1rowvy/outry/releases/latest).

Приложение обновляется само: при запуске проверяет новую версию и предлагает установить её и
перезапуститься. Обновления подписаны и проверяются перед установкой. На Linux сами обновляются только
AppImage; `.deb` и `.rpm` обновляются установкой нового пакета.

<Aside type="caution">
Сборки для macOS пока не нотаризованы. Если при первом запуске macOS пишет, что приложение повреждено,
выполните `xattr -dr com.apple.quarantine /Applications/Outry.app`.
</Aside>
