import { Steps, Aside } from '@astrojs/starlight/components';

<Steps>

1. Установите CLI (Linux):

   ```sh
   curl -fsSL https://raw.githubusercontent.com/1rowvy/routy/master/install.sh | sh
   ```

   Приложение и другие платформы — в разделе [Установка](/routy/ru/install/).

2. Создайте проект в своём репозитории:

   ```sh
   cd my-service
   routy init
   ```

   Появятся `api/env.toml` с окружениями `dev` и `prod` и пример запроса `api/health.routy`.

3. Укажите адрес API в `api/env.toml`:

   ```toml title="api/env.toml"
   default = "dev"

   [env.dev]
   base = "http://localhost:8080"

   [env.prod]
   base = "https://api.example.com"
   ```

4. Напишите запрос. Имя пишется перед методом, путь дописывается к `base`:

   ```routy title="api/users/list.routy"
   ListUsers: GET /users {
     query { page: 1 }

     expect {
       status == 200
       body.items.length > 0
     }
   }
   ```

   Самый короткий запрос — одна строка: `GET /health`.

5. Запустите:

   ```sh
   routy run api/users/list.routy
   routy run ListUsers        # по имени
   routy run api              # все *.routy и *.http внутри api/ по алфавиту
   routy run api --env prod   # другое окружение
   ```

   ```txt
   ✓ api/users/list.routy  ListUsers  GET http://localhost:8080/users?page=1  200 OK  12ms 532B
       ✓ status == 200
       ✓ body.items.length > 0
   ```

</Steps>

<Aside type="tip">
Удобнее мышкой? Откройте ту же папку в [приложении](/routy/ru/guides/desktop-app/) — оно читает те же
файлы, а правки из редактора появляются сразу.
</Aside>

Есть сервис на Go? `routy import go .` создаст запрос для каждого роута chi, gin или `net/http`, а
`routy check` потом подскажет, когда код и запросы разойдутся, — см.
[Импорт роутов из Go](/routy/ru/guides/import-go/).

Уже есть `.http`-файлы? `routy convert api/` перепишет их в `.routy` — см.
[Файлы .http](/routy/ru/guides/request-format/).
