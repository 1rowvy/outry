---
title: env.toml
description: Все ключи файла проекта env.toml.
---

`env.toml` отмечает корень проекта (обычно `api/`) и описывает его окружения.

```toml title="api/env.toml"
project = "billing-api"   # необязательно
default = "dev"           # необязательно
secrets = ["token"]       # необязательно

[vars]
version = "v1"

[env.dev]
base = "http://localhost:8080"

[env.prod]
base = "https://api.example.com"
```

| Ключ | Описание |
|------|----------|
| `project` | Пространство имён для секретов и сохранённых значений. По умолчанию — имя папки проекта или родительской папки, если она называется `api` |
| `default` | Окружение, если не указан `--env`. По умолчанию — первое по алфавиту |
| `secrets` | Имена переменных-секретов. Значения — в хранилище паролей или `OUTRY_*`; по списку `outry vars` и приложение подсказывают, каких не хватает |
| `[vars]` | Переменные, общие для всех окружений |
| `[env.<имя>]` | Окружение; его переменные перекрывают `[vars]` |
| `[import.middleware]` | Заголовки, которые нужны запросам к роутам за middleware в Go: `AuthRequired = { headers = { Authorization = "Bearer ${Login().body.token}" } }`. Для `outry import go`, см. [Middleware](/outry/ru/guides/import-go/#middleware) |

Значения — строки, числа или булевы; не-строки подставляются как написаны (`port = 8080` → `8080`).
Неизвестные ключи — ошибка, так что опечатки вроде `defualt` не пройдут незамеченными.

Секретам здесь не место — см. [Секреты](/outry/ru/guides/secrets/).
