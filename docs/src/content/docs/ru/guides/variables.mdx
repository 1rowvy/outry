В `.routy` переменная — просто имя: `customer: user_id`, а в строке — `${name}`, в пути — `{name}`; в
`.http` — `{{name}}`. Значения берутся из `api/env.toml`, из предыдущих ответов, из командной строки, из
переменных окружения и из системного хранилища паролей.

```routy
GET /users/{id} {
  query { version }
  headers { Authorization: "Bearer ${token}" }
}
```

## Окружения

```toml title="api/env.toml"
default = "dev"           # используется, если не указан --env

[vars]                    # общие для всех окружений
version = "v1"

[env.dev]
base = "http://localhost:8080"

[env.prod]
base = "https://api.example.com"
version = "v2"            # перекрывает [vars]
```

```sh
routy run api              # dev
routy run api --env prod   # prod
routy envs                 # список окружений, * — по умолчанию
```

Все ключи — в [справочнике env.toml](/routy/ru/reference/env-toml/).

## Откуда берётся значение

Для переменной Routy берёт первое найденное значение сверху вниз:

| # | Источник | Пример |
|---|----------|--------|
| 1 | Переопределения из командной строки | `routy run api --var id=42` |
| 2 | Значения, сохранённые `save` | `save token = body.access_token` |
| 3 | Переменные окружения процесса `ROUTY_<ИМЯ>` | `ROUTY_TOKEN=… routy run api` |
| 4 | Активное окружение `[env.<имя>]`, затем `[vars]` | `base = "http://localhost:8080"` |
| 5 | Системное хранилище паролей | `routy secret set token` |

Имя переменной окружения — `ROUTY_` плюс имя переменной в верхнем регистре, где всё, кроме букв и цифр,
заменено на `_`: `access-token` → `ROUTY_ACCESS_TOKEN`.

Если каких-то переменных не хватает, запрос не отправляется, а все недостающие имена выводятся сразу:

```txt
✗ api/users/get.routy  GetUser
    undefined variable(s): base, id
```

В `.routy` сначала ищутся имена, объявленные в самом запросе: аргументы вызова,
[`params`](/routy/ru/reference/routy-format/#параметры) и их значения по умолчанию, потом `let` файла, потом
таблица выше. `routy check --env prod` перечисляет переменные, которых нет в окружении, ничего не
отправляя.

## Генерируемые значения

В `.routy` это функции — `uuid()`, `now()`, `nowIso()`, `randomInt(1, 100)`, `randomString(8)`; см.
[встроенные функции](/routy/ru/reference/routy-format/#встроенные-функции).

### Динамические переменные в .http

Имена на `$` генерируются при каждой подстановке, так что каждый запрос (и каждое вхождение) получает
новое значение:

| Переменная | Значение |
|------------|----------|
| `{{$uuid}}` | Случайный UUID v4 |
| `{{$timestamp}}` | Текущее Unix-время в секундах |
| `{{$randomInt}}` | Случайное целое от 0 до 999 |
| `{{$randomInt 1 100}}` | Случайное целое от `min` (включительно) до `max` (не включая) |

```http
POST {{base}}/orders
Idempotency-Key: {{$uuid}}

{"amount": {{$randomInt 1 100}}, "created": {{$timestamp}}}
```

## Просмотр переменных

`routy vars` выводит итоговое значение каждой переменной и её источник; секреты замаскированы:

```sh
routy vars --env prod
```

В приложении тот же список для выбранного окружения — на вкладке **Variables** правой панели. См.
[`routy vars`](/routy/ru/reference/cli/#routy-vars).

## Сохранённые значения

Значения из `save` (`> save` в `.http`) доступны следующим запросам в этом же запуске **и** запоминаются между запусками —
отдельно для каждого проекта и окружения. Хранятся они вне репозитория, в `~/.local/share/routy/state/`
(Linux), потому что чаще всего это токены.

С флагом `--fresh` сохранённые значения не читаются и не записываются:

```sh
routy run api --fresh
```

Совсем забыть сохранённые значения можно кнопкой **Clear saved** на вкладке **Variables** в приложении.

Ответы запросов с [`cache: 30m`](/routy/ru/reference/routy-format/#кеширование) лежат в том же файле, пока не
устареют; `--fresh` и **Clear saved** их тоже пропускают и забывают.

## Как находится проект

Routy ищет `env.toml` или `api/env.toml`, начиная с запускаемого файла и поднимаясь по родительским
папкам до корня репозитория (папки с `.git`). Папка с `env.toml` — корень проекта. Указать его явно можно
через `--project <папка>`.

<Aside>
Без `env.toml` Routy тоже работает, но окружений нет — каждая переменная должна прийти из `--var`,
`ROUTY_*`, `save` или хранилища паролей.
</Aside>
