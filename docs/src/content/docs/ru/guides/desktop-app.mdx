Приложение работает с теми же файлами, что и CLI. Оно ничего не импортирует и не хранит коллекцию у
себя — оно открывает папку вашего проекта.

## Открытие проекта

Нажмите **Открыть проект** и выберите репозиторий (или папку `api/`). Routy находит `env.toml` так же,
как CLI. Если в папке нет `env.toml`, приложение предложит создать `api/env.toml` с примером окружений.

Последний проект запоминается и открывается при запуске.

## Работа с запросами

- Слева — все `.http`-файлы проекта; **+** рядом с **Запросы** создаёт новый (`users/create`
  превратится в `users/create.http`).
- Редактор проверяет синтаксис на лету и показывает ошибку с номером строки.
- Переключатель под именем проекта выбирает окружение из `env.toml`.
- **Добавить секрет** внизу слева сохраняет значение в системное хранилище паролей для текущего
  окружения.

| Клавиши | Действие |
|---------|----------|
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Enter</kbd> | Отправить запрос |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>S</kbd> | Сохранить файл |

Отправляется текущий текст редактора, даже если он ещё не сохранён, — удобно для быстрых экспериментов.

## Редактирование env.toml

Пункт **env.toml** под переключателем окружений открывает [`env.toml`](/routy/ru/reference/env-toml/)
проекта в редакторе. Приложение проверяет TOML на лету и не сохранит файл с ошибкой. После сохранения
новые окружения появятся в переключателе, а новые значения подставятся в следующий запрос. Токены и
пароли сюда не пишите — для них есть **Добавить секрет**.

## Ответ

У панели ответа четыре вкладки:

- **body** — отформатированный JSON или тело как есть;
- **headers** — заголовки ответа;
- **tests** — результат каждой `> assert` и `> save`;
- **request** — запрос ровно в том виде, в каком ушёл, после подстановки переменных.

## Живое обновление

Правьте файлы в VS Code, переключайте ветки, делайте pull — список файлов и открытый запрос обновятся
сразу. Если в приложении есть несохранённые правки, открытый файл не перезаписывается.

## Обновления

При запуске приложение проверяет новую версию. Если она есть, кнопка в боковой панели скачивает её,
устанавливает и перезапускает приложение. Обновления подписаны и проверяются перед установкой.

<Aside>
На Linux сами обновляются только сборки AppImage. Для `.deb` и `.rpm` поставьте новый пакет со
[страницы релизов](https://github.com/1rowvy/routy/releases/latest).
</Aside>
