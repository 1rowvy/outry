Приложение работает с теми же файлами, что и CLI. Оно ничего не импортирует и не хранит коллекцию у
себя — оно открывает папку вашего проекта.

## Открытие проекта

Нажмите **Open project** и выберите репозиторий (или папку `api/`). Routy находит `env.toml` так же,
как CLI. Если в папке нет `env.toml`, приложение предложит создать `api/env.toml` с примером окружений.

Последний проект запоминается и открывается при запуске.

## Работа с запросами

- Слева — все `.http`-файлы проекта; **+** рядом с **Requests** создаёт новый (`users/create`
  превратится в `users/create.http`).
- Правый клик по запросу или папке — открыть, дублировать, переименовать или удалить. **Rename / Move…**
  принимает путь, так что `users/create` → `admin/users/create` переносит файл в другую папку. При
  удалении папки удаляются только `.http`-файлы в ней, остальные остаются.
- Редактор подсвечивает синтаксис `.http` и проверяет его на лету: строка с ошибкой подчёркнута, текст
  ошибки — под редактором.
- После `{{` редактор предлагает переменные текущего окружения (из `env.toml`, `> save`, списка
  `secrets` и [динамические](/routy/ru/guides/variables/#динамические-переменные)), а в строках `>` —
  директивы, пути и операторы.
- Переключатель под именем проекта выбирает окружение из `env.toml`.
- **Add secret** внизу слева сохраняет значение в системное хранилище паролей для текущего
  окружения.

| Клавиши | Действие |
|---------|----------|
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Enter</kbd> | Отправить запрос |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>S</kbd> | Сохранить файл |
| <kbd>Ctrl</kbd> + <kbd>Space</kbd> | Показать подсказки |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>F</kbd> | Поиск по файлу |

Отправляется текущий текст редактора, даже если он ещё не сохранён, — удобно для быстрых экспериментов.

Пока запрос в пути, кнопка **Send** превращается в **Cancel**. Тем временем можно переключиться на другой
запрос и отправить его: запросы идут параллельно, у каждого файла — свой последний ответ.

## Редактирование env.toml

Пункт **env.toml** под переключателем окружений открывает [`env.toml`](/routy/ru/reference/env-toml/)
проекта в редакторе. Приложение проверяет TOML на лету и не сохранит файл с ошибкой. После сохранения
новые окружения появятся в переключателе, а новые значения подставятся в следующий запрос. Токены и
пароли сюда не пишите — для них есть **Add secret**.

## Ответ

У правой панели четыре вкладки: **Response**, **History**, **Variables** и **Routes**. У самого ответа такие виды:

- **body** — отформатированный и подсвеченный JSON, HTML или XML; кнопка поиска (или
  <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>F</kbd> внутри тела) ищет по нему;
- **preview** — для картинок и HTML-страниц; HTML показывается без выполнения скриптов;
- **headers** — заголовки ответа;
- **tests** — результат каждой `> assert` и `> save`;
- **request** — запрос ровно в том виде, в каком ушёл, после подстановки переменных.

Кнопка со стрелкой сохраняет тело в файл байт в байт.

## История

**History** — последние 100 ответов проекта: для открытого запроса или для всех. Клик открывает ответ
снова. История живёт в памяти до закрытия приложения; включите **Keep response history on disk** в меню
(☰ в шапке окна), чтобы она сохранялась между запусками. Она хранится вне репозитория, рядом с
сохранёнными значениями, а в ответах бывают токены — **Clear** её удаляет.

## Переменные

**Variables** показывает все переменные выбранного окружения, итоговое значение и откуда оно взялось —
`env.toml`, `saved`, `ROUTY_*` или `keychain`, — как [`routy vars`](/routy/ru/reference/cli/#routy-vars).
Секреты замаскированы. Секреты из списка [`secrets`](/routy/ru/reference/env-toml/), которые нигде не
заданы, помечены **missing** — рядом кнопка, чтобы добавить. **Clear saved** забывает значения из
`> save` в этом окружении.

## Роуты

**Routes** сравнивает роуты Go-сервиса с файлами запросов проекта, как
[`routy import go`](/routy/ru/guides/import-go/): новые роуты, роуты, для которых файл уже есть, и файлы,
чьего роута больше нет в коде. **Create files** создаёт запросы для новых; существующие файлы не
меняются. Кнопка синхронизации рядом с **Requests** открывает вкладку и сканирует заново. По умолчанию
Go-код ищется в папке над `api/`; нажмите на путь, чтобы выбрать другую.

## Живое обновление

Правьте файлы в VS Code, переключайте ветки, делайте pull — список файлов и открытый запрос обновятся
сразу. Если в приложении есть несохранённые правки, открытый файл не перезаписывается.

## Обновления

При запуске приложение проверяет новую версию. Если она есть, кнопка в боковой панели скачивает её,
устанавливает и перезапускает приложение. Обновления подписаны и проверяются перед установкой.

В меню (☰ в шапке окна) есть **Check for updates** и **Install updates automatically**: со вторым новая
версия скачивается и ставится в фоне и начинает работать после следующего перезапуска.

<Aside>
На Linux сами обновляются только сборки AppImage. Для `.deb` и `.rpm` поставьте новый пакет со
[страницы релизов](https://github.com/1rowvy/routy/releases/latest).
</Aside>
