<Steps>

1. Install the CLI (Linux):

   ```sh
   curl -fsSL https://raw.githubusercontent.com/1rowvy/routy/master/install.sh | sh
   ```

   The desktop app and other platforms are covered in [Installation](/routy/install/).

2. Create a project in your repository:

   ```sh
   cd my-service
   routy init
   ```

   This creates `api/env.toml` with `dev` and `prod` environments and an example request
   `api/health.routy`.

3. Point `base` at your API in `api/env.toml`:

   ```toml title="api/env.toml"
   default = "dev"

   [env.dev]
   base = "http://localhost:8080"

   [env.prod]
   base = "https://api.example.com"
   ```

4. Write a request. The path is appended to `base`; the comment above is the request's name:

   ```routy title="api/users/list.routy"
   // List users
   GET /users {
     query { page: 1 }

     expect {
       status == 200
       body.items.length > 0
     }
   }
   ```

   The smallest request is one line: `GET /health`.

5. Run it:

   ```sh
   routy run api/users/list.routy
   routy run ListUsers        # by name
   routy run api              # every *.routy and *.http under api/, in alphabetical order
   routy run api --env prod   # another environment
   ```

   ```txt
   ✓ api/users/list.routy  ListUsers  GET http://localhost:8080/users?page=1  200 OK  12ms 532B
       ✓ status == 200
       ✓ body.items.length > 0
   ```

</Steps>

<Aside type="tip">
Prefer a GUI? Open the same folder in the [desktop app](/routy/guides/desktop-app/) — it reads the same
files, and edits made in your editor show up immediately.
</Aside>

Already have `.http` files? `routy convert api/` rewrites them into `.routy` — see
[.http files](/routy/guides/request-format/).
