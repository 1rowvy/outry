# tree-sitter-routy

Tree-sitter grammar for Routy `*.routy` request files: highlighting in Neovim, Helix, Zed and other
editors that load tree-sitter grammars. Errors, completion and the rest come from the language server
`routy lsp`. Setup per editor: https://1rowvy.github.io/routy/guides/editors/

- `grammar.js` — the grammar; the format is specified in `docs/src/content/docs/reference/routy-format.mdx`,
  the reference parser is `crates/routy-core/src/lang/parse.rs`
- `src/` — generated by `tree-sitter generate`, committed so editors can build the parser without Node
- `queries/highlights.scm` — nvim-treesitter / Zed capture names; `queries/helix/highlights.scm` — Helix
- `test/corpus/` — `tree-sitter test`

```sh
npx tree-sitter-cli@0.25.10 generate   # after changing grammar.js; CI checks src/ is up to date
npx tree-sitter-cli@0.25.10 test
```
